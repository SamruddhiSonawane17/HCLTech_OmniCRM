# HCLTech_OmniCRM
## Omnichannel CRM & Sales Automation Platform

### 📌 Project Overview
OmniCRM is an Angular-based Customer Relationship Management (CRM) platform designed to help businesses manage customers, leads, sales activities, communication records, and follow-ups through a single dashboard.

The platform provides an organized and user-friendly interface to simplify customer relationship management and sales operations.

### ✨ Features
- **Dashboard:** View an overview of CRM activities.
- **Customer Management:** Add and manage customer information.
- **Lead Management:** Track and organize potential customers.
- **Sales Pipeline:** Monitor sales opportunities and their progress.
- **Communication Activity:** Maintain communication records.
- **Tasks & Follow-ups:** Organize tasks and reminders.
- **Reports & Analytics:** View reports and export summary data as CSV.
- **Workspace Settings:** Manage application preferences.
- **Authentication UI:** Sign-in and sign-up demo functionality.

### 🛠️ Technologies Used
- Angular
- TypeScript
- HTML5
- CSS3
- RxJS
- Chart.js
- Bootstrap Icons
- Browser Local Storage

### ⚙️ Installation and Setup

**1. Clone the repository**
```bash
git clone https://github.com/SamruddhiSonawane17/HCLTech_OmniCRM.git
```

**2. Navigate to the project folder**
```bash
cd HCLTech_OmniCRM
```

**3. Install dependencies**
```bash
npm install
```

**4. Run the application**
```bash
ng serve -o
```

**5. Open in browser**

Visit:
`http://localhost:4200/`

### 💾 Data Storage
The current frontend demo uses Browser Local Storage to maintain sample customers, leads, deals, tasks, communication interactions, and settings. It does not use a connected production backend or real external messaging services.
